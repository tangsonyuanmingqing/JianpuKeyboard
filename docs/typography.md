# 排版规范

应用内所有文字都从 `AppTypography` 或 `ThemeData.textTheme` 获取，避免页面各自指定字体、字号与字重。

## 主题与前景色

- 应用提供白色主题和深灰黑主题；新用户默认白色主题，用户选择会保存在本机。
- 页面标题、正文、列表标题和输入文字使用主题的 `onSurface`；说明、占位和列表副标题使用 `onSurfaceVariant`。
- 当前选中的曲谱列表项使用主题强调色和强调容器背景，不能用白色文字表示选中状态。
- 页面右上角的外观按钮可在两种主题之间切换。导出的简谱图片与检查图始终保持白底深字，便于分享和打印。

## 字体

- 界面、按钮、菜单、表格和检查图：Noto Sans CJK SC
- 数字简谱文本输入、歌词文本输入、纯文本预览和纯文本图片导出：Noto Sans Mono CJK SC

等宽字体用于依赖空格和字符显示宽度对齐的内容。智能表格由单元格尺寸负责对齐，因此格内文字继续使用界面字体。

## 语义层级

| 用途 | 字重 | 常用字号与行高 |
| --- | --- | --- |
| 页面主标题 | 700 | 28/36、24/32 |
| 区块和列表标题 | 600 | 22/28、16/24、14/20 |
| 按钮、标签和菜单项 | 500 | 14/20、12/16、11/16 |
| 正文、输入和表格内容 | 400 | 16/24、14/20、12/16 |

歌曲名图片标题使用 22/28、700；纯文本简谱使用等宽 16/24、400。检查图使用标题 22/28、700、表头 14/20、600、单元格 16/24、400。

## 开发规则

- 新页面优先使用 `Theme.of(context).textTheme`。
- 简谱专用区域使用 `AppTypography.of(context).notationBody`。
- 表格和检查图使用 `AppTypography` 的表格、检查图令牌；表格缩放只改变令牌提供的字号。
- 需要错误、提示或禁用颜色时，从已有语义样式调用 `copyWith(color: ...)`，不重新定义字体参数。
- 页面不应假定白色背景或深色背景；普通文字从 `ThemeData.textTheme` 或 `AppTypography.of(context)` 获取前景色。
- 仅 `lib/app/theme/` 可以创建 `TextStyle` 或声明字体家族、字号和字重。测试会阻止其他目录新增此类声明。

内置 Noto CJK 字体及其 SIL Open Font License 1.1 位于 `assets/fonts/`。
