# 曲谱库与备份

## 保存曲谱

在转换页点击「保存到曲谱库」即可保存当前数字简谱和歌词。歌曲名必填；歌手、标签和备注可选。标签输入后按 Enter 添加，也可以选择已有标签。

保存时，如果当前转换结果有效，应用还会一并保存：

- 字母简谱文字结果
- 当时使用的键盘映射
- 转换产生的提示信息

存在解析错误时仍可保存输入草稿，但不会保存错误的转换结果。

已从曲谱库载入的歌曲会显示「保存修改」；需要创建副本时使用「另存为」。当前编辑内容和关联歌曲会随临时草稿一起在重启后恢复。

## 浏览与载入

点击转换页右上角的曲谱库图标可打开曲谱库。列表支持：

- 按歌曲名、歌手、标签或备注搜索
- 按标签筛选
- 按最近修改时间或歌曲名排序

进入歌曲详情后，点击「一键填入转换页」即可恢复数字简谱和歌词。替换现有输入前会要求确认。

详情页可以预览、复制和导出已保存的字母简谱图片，也可以选择「应用保存的键位」。应用键位会替换当前键位，并清除当前转换结果。

## 结果待更新

如果保存了新输入但尚未重新转换，应用会保留之前成功的字母简谱，并标记为“转换结果待更新”。重新转换后再次保存，会用新的结果、键位快照和提示信息替换旧快照。

## 导入与导出

曲谱库右上角提供全库 JSON 导入和导出；歌曲详情页可导出单曲 JSON。

备份文件是可阅读、未加密的 JSON，包含所有歌曲资料、原始输入、已保存结果、键位快照、提示信息和时间。导入前会校验整个文件的版本和记录结构；文件无效时不会写入任何内容。若备份与本机存在相同记录，可选择保留本机内容或全部覆盖。

删除歌曲前会要求确认，删除后可通过提示条的「撤销」恢复。
