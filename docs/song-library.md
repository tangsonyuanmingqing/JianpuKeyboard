# 曲谱库与备份

## 保存曲谱

在转换页标题栏下方填写歌曲名后，点击「保存到曲谱库」即可保存当前数字简谱和歌词。智能表格模式会同时保存表格结构和兼容文本；文本模式保持原输入。歌曲名必填；歌手、标签和备注可选。标签输入后按 Enter 添加，也可以选择已有标签。若尚未填写歌曲名，保存对话框会要求补充，保存后会同步回主页。

保存时，如果当前转换结果有效，应用还会一并保存：

- 字母简谱文字结果
- 当时使用的键盘映射
- 转换产生的提示信息

存在解析错误时仍可保存输入草稿，但不会保存错误的转换结果。

已从曲谱库载入的歌曲会显示「保存修改」；需要创建副本时使用「另存为」。副本默认以“原歌曲名 - 副本”命名，并继承歌手、标签和备注。当前编辑内容、歌曲名和关联歌曲会随临时草稿一起在重启后恢复。

## 浏览与载入

点击转换页右上角的曲谱库图标可打开曲谱库。列表支持：

- 按歌曲名、歌手、标签或备注搜索
- 按标签筛选
- 按最近修改时间或歌曲名排序

进入歌曲详情后，点击「一键填入转换页」即可恢复数字简谱和歌词。智能表格歌曲会同时恢复行列、谱词分组和输入模式。替换现有输入前会要求确认。

详情页可以预览、复制和导出已保存的字母简谱图片，也可以选择「应用保存的键位」。保存了智能表格且转换结果仍有效的歌曲会在纯文本预览下方显示字母简谱表格，并可使用全局表格大小控制器和右下角拖动角调整预览区域。复制文本和图片会在字母简谱前显示歌曲名；图片文件名使用“歌曲名-字母简谱-时间戳”。应用键位会替换当前键位，并清除当前转换结果。

## 结果待更新

如果保存了新输入但尚未重新转换，应用会保留之前成功的字母简谱，并标记为“转换结果待更新”。重新转换后再次保存，会用新的结果、键位快照和提示信息替换旧快照。

待更新状态下，详情页只展示已保存的旧纯文本结果并明确标记；不会用当前输入临时伪造一份表格结果。

## 导入与导出

曲谱库右上角提供全库 JSON 导入和导出；歌曲详情页可导出单曲 JSON。

备份文件是可阅读、未加密的 JSON。v2 包含歌曲资料、规范文本、可选智能表格、已保存结果、键位快照、提示信息和时间；仍可导入旧的 v1 备份。导入前会校验整个文件的版本和记录结构；文件无效时不会写入任何内容。若备份与本机存在相同记录，可选择保留本机内容或全部覆盖。

删除歌曲前会要求确认，删除后可通过提示条的「撤销」恢复。

## 本地存储与恢复中心

v1.6.0 起，曲谱库和当前草稿保存到应用支持目录中的版本化 JSON 文件。应用使用临时文件、刷盘和原子替换避免半写文件，并串行执行写入。首次升级会迁移旧本机数据，旧数据保留不删除。

曲谱库工具栏的「恢复中心」分别管理曲谱库和当前草稿：

- 可创建带可选备注的手动快照，并预览、导出或删除。
- 曲谱库在保存、删除、导入和恢复前自动备份。
- 草稿变化后创建自动快照，相同内容不重复保存，后续快照最多每 5 分钟一份。
- 两类快照各保留最近 20 份；恢复前会先备份当前内容。
- 主文件损坏时会禁止继续覆盖。没有可用快照时，需要先导出损坏的原始数据，才能重置为空内容。
