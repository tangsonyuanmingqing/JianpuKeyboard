# Jianpu Keyboard v1.6.1

Windows x64 维护版本，2026-09-27。

## 本次更新

- 重构输入、转换输出和曲谱库预览的表格滚动条，修复选中单元格后底部滑块不可见、无法操作的问题。
- 每表每轴最多一条滚动条；有溢出时常显，底部和右侧各固定预留 24 逻辑像素，不覆盖格子，右下角保留调整大小区域。
- 滑块拖动和轨道点击保留选中格、编辑焦点、光标及输入法组词；冻结列同步和页面自身滚动条保留。
- 修复 Windows PowerShell 5.1 打包脚本编码故障、相对输出路径和日志收集；默认产物放入 `dist\yyyy-MM-dd\HH-mm\`，提供快速打包回归测试。
- 不改变曲谱数据格式、缩放规则或存储位置。
