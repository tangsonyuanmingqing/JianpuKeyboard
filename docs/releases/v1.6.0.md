# Jianpu Keyboard v1.6.0

Windows x64 版本，2026-09-27。

## 本次更新

- 曲谱库与草稿升级为版本化原子 JSON 存储，首次启动自动迁移旧本机数据并保留旧值。
- 新增恢复中心：曲谱库／草稿快照的创建、预览、恢复、导出与删除；两类各保留最近 20 份。
- 草稿显示保存状态，失败时可重试；正常退出前刷新待写入内容，失败时取消退出。
- 优化智能表格的可见行列渲染、单元格复用和问题坐标索引；密集错误图标改为行级绘制，保留格子边框、提示与输入行为。
- 统一歌词输入／粘贴分格规则，连续数字歌词保留为一个词；加强输入法组词、焦点、滚动、撤销与配对行拖动回归。
- 智能表格输入修改后保留旧预览并标记“结果待更新”，完整转换仍由用户点击触发。
- 新增全局表格大小，输入、输出和曲谱库预览共用 0%–100% 比例；不改变曲谱数据或导出图片。
- 统一内置中文字体和谱词等宽排版，提供白色／深灰黑主题切换；导出图片保持白底深字。
- Windows 支持单实例激活、窗口置顶，以及可选择安装范围和快捷方式的安装向导。
- 按职责集中编辑时校验、表格滚动同步与存储状态转换，保留各域的状态和控制器所有权。

## 下载与升级

[下载 v1.6.0](https://github.com/tangsonyuanmingqing/JianpuKeyboard/releases/tag/v1.6.0)。

- `JianpuKeyboard-v1.6.0-windows-setup.exe`：安装版。
- `JianpuKeyboard-v1.6.0-windows-portable.zip`：解压后运行 `jianpu_keyboard.exe`；保留整个目录。
- `SHA256SUMS-v1.6.0.txt`：交付文件的 SHA-256 校验值。
- `JianpuKeyboard-v1.6.0-windows-performance-reports.zip`：性能基线、失败探测、诊断与最终四场景原始记录。

升级前建议从曲谱库导出全库 JSON，保存并正常关闭旧版，再运行安装程序。新版本会自动迁移旧数据；保留的旧值是升级前副本，降级不会同步升级后新修改的内容。便携版与安装版使用本机应用支持目录，不提供独立数据沙箱；请勿将切换启动方式当作备份。

安装包未配置代码签名。字体及其 SIL Open Font License 1.1 随包提供。

## 验证与边界

2026-09-27 发布前全量 `flutter test`：399 项通过；`flutter analyze` 无问题，Windows Release 构建与 Inno Setup 编译通过。

2026-09-26 在当前开发机进行 Windows 原生 Profile 性能验证：100×100 表格，默认／大面板 × 有效／9,999 错误格子四场景，各三轮，共 3,000 个正式响应样本。输入、选择、纵滚、横滚、撤销的每轮及合并 P95 均低于 100ms。大面板密集错误横滚合并 P95 从 120.787ms 降至 82.228ms；选择与撤销略有增加，但仍在预算内。

测量止于结果帧光栅化完成，不等于物理输入到显示器的端到端延迟。未覆盖其他设备、窗口、DPI、真实中文输入法提交或大输出表格的原生性能；Profile 自动化验收不替代人工安装包测试。详见[完整性能验证记录](https://github.com/tangsonyuanmingqing/JianpuKeyboard/blob/v1.6.0/docs/windows-ui-performance.md)。

仍采用无状态全表语法校验，未引入增量缓存；页面继续负责流程编排，没有单纯为缩短文件进行机械拆分。当前正式支持与验证目标仅为 Windows x64。
