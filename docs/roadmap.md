# 路线图

## V1

文字数字简谱 → 字母键盘简谱。

包含解析、映射、歌词对应、文字输出、一键复制。

## V1.1（已完成）

- [x] 更好的歌词对齐提示
- [x] 更完善的文本编辑
- [x] 更清晰的错误定位
- [x] 自定义键盘映射及本地保存

## 智能输入（已完成）

- [x] 行列坐标表格与谱词类型
- [x] 表格直接转换和格子级问题定位
- [x] 文本互转、批量粘贴、矩形选区和快捷键
- [x] 草稿、曲谱库和 v2 备份
- [x] 干净图片与坐标检查图
- [x] 单元格级插入删除、跨类型移动确认与撤销

## V1.6（功能已完成，四场景性能验收通过）

交付内容与升级注意事项见 [v1.6.0 发布说明](releases/v1.6.0.md)。

- [x] 版本化文件存储、原子写入与旧数据迁移
- [x] 草稿保存状态、失败重试与退出前刷新
- [x] 曲谱库与草稿恢复快照
- [x] Windows 单实例启动与本地安装/便携包
- [x] Windows 窗口置顶、主题切换与内置中文字体
- [x] 100×100 智能输入表格真实界面操作 P95＜100ms（默认／大面板、有效／9,999 错误四场景各三轮通过；见[性能验证记录](windows-ui-performance.md)）
- [x] 默认面板的有效数据与密集错误格子真实界面性能复核（三轮，见[验证记录](windows-ui-performance.md)）
- [ ] 其他设备／窗口／DPI、物理输入法与显示端到端性能复核

## V2（下一阶段）

图片数字简谱 → 统一音乐模型 → 字母键盘简谱。

图片输入必须进入与文字输入相同的 Score 模型。

## V2.x

- 图片 / PDF 导出
- 打印

## V3

Playback Engine。

## V3.x

Keyboard Executor。这是可选平台能力，不要求四端一致。

- Mouse Executor
- Macro / Script
- MIDI
