# 路线图

## V1

文字数字简谱 → 字母键盘简谱。

包含解析、映射、歌词对应、文字输出、一键复制。

## V1.1（已完成）

- [x] 更好的歌词对齐提示
- [x] 更完善的文本编辑
- [x] 更清晰的错误定位
- [x] 自定义键盘映射及本地保存

## V2

图片数字简谱 → 统一音乐模型 → 字母键盘简谱。

图片输入必须进入与文字输入相同的 Score 模型。

## V2.x

- 图片 / PDF 导出
- 打印

## V3

Playback Engine。

## V3.x

Keyboard Executor。这是可选平台能力，不要求四端一致。

## V4

- Mouse Executor
- Macro / Script
- MIDI

版本号可随实际开发调整。未到对应版本时，不提前把这些能力做进 Core。
