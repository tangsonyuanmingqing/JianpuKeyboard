# V1.2 规格

## Problem Statement

文字转换已经可用，但新用户不容易快速写出正确输入，编辑中的内容会在重启后丢失，转换结果也不便于以稳定排版分享。Windows 用户还缺少可直接安装的发行方式。

## Solution

V1.2 保持文字转换为核心，增加示例、应用内格式说明、自动恢复草稿与 PNG 分享图。首发以 Windows x64 为目标，提供可选安装范围的传统安装包和 ZIP 便携版。

## User Stories

1. 作为新用户，我想从空白页面载入示例，以便快速理解输入格式。
2. 作为用户，我想为每个示例选择填入两个输入框或标准文档，以便学习两种支持的输入形式。
3. 作为正在编辑的用户，我想在替换非空输入前得到确认，以免丢失内容。
4. 作为用户，我想查看应用内格式说明，以便查阅语法、键位和歌词对齐规则。
5. 作为用户，我想从格式说明复制或使用示例，以便立即开始转换。
6. 作为用户，我想在停止输入后自动保存草稿，以便意外关闭后仍能恢复。
7. 作为用户，我想知道草稿已恢复，以便理解页面中的已有内容。
8. 作为用户，我想在清空前确认，并在五秒内撤销，以便避免误删。
9. 作为用户，我想复制纯文本结果，以便发送到聊天工具。
10. 作为用户，我想将有效转换结果导出为 PNG，以便稳定地分享字母简谱与歌词。
11. 作为用户，我想让长谱在图片中按完整 token 换行，以便手机阅读时保持音符和歌词的关系。
12. 作为有歌词警告的用户，我想仍能导出干净图片，以便按自己的意图分享结果。
13. 作为 Windows 用户，我想下载安装包或便携版，以便按自己的方式使用应用。

## Implementation Decisions

- `ConverterInputNotifier` 是输入、示例载入、草稿保存、清空和撤销的唯一状态入口。
- 草稿只保存数字简谱与歌词；停止输入约一秒后写入本机存储。启动时恢复草稿，不恢复转换结果。
- 示例使用原创且可自由发布的内容。每个示例可填入分离输入框或 `[谱]` / `[词]` 标准文档；替换非空输入必须确认。
- 格式说明作为应用内页面，覆盖语法、默认键位、歌词对齐与可操作示例。
- 图片导出只接收成功转换后的结构化结果，使用 Windows 文件保存窗口导出 PNG。图片没有标题、日期或警告；默认文件名包含导出日期时间。
- 图片布局按完整音符 token 换行，避免把音符与对应歌词列拆开。
- 清空会删除已保存草稿；确认后显示五秒撤销入口。撤销会恢复输入并重新保存草稿。
- Windows 首发为 x64。传统安装包允许选择当前用户或全部用户，并让用户选择开始菜单和桌面快捷方式。首版未签名，Release 同时提供 SHA-256 校验文件和 ZIP 便携版。
- 使用 MIT 许可证，版权持有人为 `tangsonyuanmingqing`。

## Testing Decisions

- 草稿存储、保存延迟、清空和恢复在存储边界使用单元测试。
- 示例转换、替换确认、撤销、格式说明与导出按钮状态在转换页面使用 widget 测试。
- 图片换行逻辑提取为纯 Dart 布局服务，以 token 行为测试，而不依赖像素快照。
- Windows 文件保存与最终 PNG 由 Windows 集成测试验收。

## Out of Scope

- 图片识谱、OCR、PDF 导出、云端同步、曲谱列表、自动更新、代码签名、ARM64、macOS、Android 与 iOS 发布。
- 播放、自动按键、MIDI、宏和复杂节奏系统。

## Further Notes

转换继续保持手动触发。警告不阻止复制或 PNG 导出；解析错误没有可导出的结果。
